# React Dashboard District Filter

โปรเจคนี้เป็นตัวอย่าง Dashboard สำหรับแสดงข้อมูลรายอำเภอและการกรองข้อมูลแบบโต้ตอบ โดยเน้นความชัดเจนของการนำเสนอข้อมูลและประสบการณ์ผู้ใช้งานที่อ่านง่าย

## ภาพรวม

โครงการนี้ใช้ React และ Vite เพื่อสร้างหน้า dashboard ที่สามารถ:

- แสดงข้อมูลเชิงสถิติแบบรวมและรายอำเภอ
- กรองข้อมูลตามพื้นที่
- แสดงแนวโน้มและการแจ้งเตือนที่ชัดเจน
- เหมาะสำหรับการแสดงรายละเอียดข้อมูลที่ต้องการนำเสนอในรูปแบบ dashboard

## Stack ที่ใช้

- React
- Vite
- Recharts
- Lucide React

## โครงสร้างโฟลเดอร์

```text
react-dashboard-district-filter/
└── frontend/
    ├── src/
    ├── index.html
    ├── package.json
    ├── pnpm-lock.yaml
    └── vite.config.js
```

## วิธีเริ่มต้นใช้งาน

```powershell
cd react-dashboard-district-filter/frontend
pnpm install
pnpm dev
```

## วัตถุประสงค์การใช้งาน

- สาธิตการแสดงผลข้อมูลเชิงพื้นที่
- แสดงแนวทางการทำ dashboard สำหรับข้อมูลสาธารณสุขหรือข้อมูลเชิงธุรกิจ
- เป็นส่วนหนึ่งของ portfolio ที่แสดงความสามารถด้าน frontend และ data visualization

> โครงการนี้เหมาะสำหรับการแสดงแนวทางการออกแบบ UI และการตีความข้อมูลแบบผู้ใช้มีประสิทธิภาพ
