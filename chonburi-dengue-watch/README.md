# Chonburi Dengue Watch

A full-stack prototype for monitoring and forecasting dengue cases across 11 districts in Chonburi Province. The project combines a FastAPI backend, a React dashboard, and a synthetic machine learning pipeline to demonstrate how public-health surveillance data can be visualized and used for risk assessment.

## Project goals

- Monitor dengue-related case records by district and date
- Visualize trends with a dashboard and risk alerts
- Predict future case load using a trained regression model
- Demonstrate a data-to-dashboard workflow suitable for presentation and prototyping

## Architecture

```text
React Frontend
      │
      ▼
FastAPI Backend
      │
      ├── SQLite database for observations and predictions
      ├── Pydantic validation for requests and responses
      └── RandomForestRegressor model saved as joblib
              │
              ▼
      ML training pipeline using synthetic district data
```

## Main features

- Dashboard with summary cards and district-level risk view
- Observation form for recording case counts and environmental conditions
- Prediction endpoint for estimated dengue burden
- Synthetic dataset generation for reproducible experimentation
- Risk classification based on predicted count and trend change

## Quick start

### 1) Backend

```powershell
cd chonburi-dengue-watch/backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m app.ml.train
uvicorn app.main:app --reload --port 8000
```

Open the API docs at http://localhost:8000/docs

### 2) Frontend

```powershell
cd chonburi-dengue-watch/frontend
pnpm install
pnpm dev
```

The frontend expects the backend at http://localhost:8000 by default.

## Data and ML notes

- The project uses synthetic data generated by a reproducible script.
- The model is trained on district-level weekly features and risk signals.
- Risk labels are based on predicted case count and relative growth compared with prior values.

> This project is intended for demonstration, prototyping, and academic presentation. It should not be used for real public-health operational decisions without validation with real field data and domain experts.
